# 学習カード 表裏フリップ 要件定義

対象: `apps/ios-swiftui/UsalingoIOS/Features/Study/StudyCardView.swift` /
`StudySessionView.swift`。他エージェントへの引き継ぎ用。

## 1. 目的

カードに入り切らない情報を、表＝主情報 / 裏＝補足情報 に分け、裏面のみ縦
スクロールで扱えるようにする。

## 2. 面の構成

| 面 | 載せるもの |
| --- | --- |
| 表 | 単語、イラスト、品詞、意味（訳）、例文（英）、例文（訳）、学習ステータス系ピル |
| 裏 | 類義語、語源、その他の補足。将来の追加もここへ |

- 表の「意味・例文」は回答前は伏せる（現行の `showAnswer` 相当を維持）。
- 裏に出す情報が 1 件も無いカードでは、裏返さずプレースホルダ 1 行
  （例「補足情報はまだありません」）を表示する。空の裏面は作らない。

## 3. タップ操作

| 状態 | タップ | 遷移後 |
| --- | --- | --- |
| 表・回答前 | 1 回目 | 表・回答表示 |
| 表・回答後 | 2 回目以降 | 裏 |
| 裏 | タップ | 表・回答表示（回答前には戻さない） |

- カード送り（次の単語）で回答前・表にリセット。
- 反転は Y 軸フリップアニメーション。触覚は既存 `HapticFeedbackService.tap()`。

## 4. スクロール

- 裏面のみ縦スクロール。表面はスクロールしない。
- **必要なときだけ**: 中身が枠に収まる場合はスクロールを無効にし、バウンス
  させない。収まらない場合のみ有効化し、続きがあることを下端のフェードか
  スクロールインジケータで示す。
- カードの外形（`aspectRatio(0.74)`、`maxWidth: 350`）は表裏とも変えない。

## 5. ジェスチャ調停（最重要）

同一領域に 3 つの操作が重なる。優先順位と条件を守ること。

1. **左端の戻るスワイプ**（既存 `StudyBackSwipeEnabler` / `backSwipeProtectedRegion`）
   — 現行挙動を変えない。
2. **横スワイプでの ○×**（`StudySessionView` の `DragGesture`、しきい値 110）
   — 開始直後の移動量で **横成分 > 縦成分** のときのみ発火するよう方向ゲート
   を追加する。現行は方向を見ていないため、裏面に `ScrollView` を入れると
   競合する。
3. **裏面の縦スクロール** — 縦成分優位のときのみ。

- スクロール中の指離しを反転タップと誤認しないこと。
- 背面（次カード）は `allowsHitTesting(false)` のまま。スクロール不要。

## 6. データ

`WordCard` に類義語・語源のフィールドは**現在存在しない**
（`apps/ios-swiftui/UsalingoIOS/Models/WordCard.swift`）。

- 本チケットの範囲は UI と、`WordCard` へのオプショナルなフィールド追加まで。
- Supabase 側のカラム/取得は未確認。データが無い間は §2 のプレースホルダで
  成立させ、スキーマ変更は別チケットに切り出す。

## 7. 受け入れ条件

- [ ] 表・回答前 → タップ → 回答表示 → タップ → 裏 → タップ → 表・回答表示
- [ ] 裏の内容が短いときスクロールもバウンスも起きない
- [ ] 裏の内容が長いとき最後まで読め、続きがあると視覚的に分かる
- [ ] 裏面を縦にスクロールしてもカードが左右に飛ばない／○×が誤発火しない
- [ ] 裏面から横スワイプで ○× が従来どおり効く
- [ ] 画面左端からの戻るスワイプが従来どおり効く
- [ ] 次カードへ進むと表・回答前に戻る
- [ ] 補足情報ゼロのカードでプレースホルダが出る
- [ ] シミュレータのスクリーンショット（表・回答前 / 表・回答後 / 裏）を添付

## 8. 非対象

- カード外形・寸法の変更、カード送りアニメーションの変更
- SRS ロジック、音声再生
- Supabase スキーマ変更（別チケット）
