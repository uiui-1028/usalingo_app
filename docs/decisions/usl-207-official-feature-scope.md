# USL-207 Ver.2.0の正式な機能範囲

決定日: 2026-08-16

対象: `apps/ios-swiftui/` の現在のSwiftUIアプリ

## 決めること

新しい説明書に「現在使える正式なVer.2.0機能」として載せる範囲を決める。
旧Flutter版の説明や、画面だけあって動作が完成していない項目は、現在仕様と混ぜない。

## 判断の基準

- 現在のSwiftUIコードで、利用開始から保存までの流れを確認できる。
- 制限がある機能は、その制限も一緒に説明できる。
- 将来の実装予定を、現在使える機能のように約束しない。

## 正式に載せる

| 機能 | 正式な範囲 | 理由 |
| --- | --- | --- |
| アカウント | メールアドレスとパスワードによる登録・ログイン | 現在のSwiftUIアプリに認証画面と認証処理がある。 |
| 公式コンテンツ学習 | 公式デッキを開き、画像付き単語カードへ正解・不正解で回答する | 現在の中心となる学習フローである。 |
| 学習記録 | 回答結果と次回復習予定を利用者ごとにSupabaseへ保存する | `user_card_progress` を使う保存処理がある。 |
| 配布音声 | 運営が用意した音声アセットを再生する | 現在は音声URLを `AVPlayer` で再生している。 |
| ユーザーごとの単語編集 | ログイン中の利用者が、単語、意味、例文、画像参照を自分用に上書きする | `user_word_overrides` へ利用者別に保存し、公式データ自体は変更しない。オンライン接続が必要。 |
| 表示のカスタマイズ | アクセント色と学習カードの角丸を端末内に保存する | 現在動作する設定だけに限定する。設定はアカウント間・端末間では同期しない。 |

## 今は載せない

| 項目 | 載せない理由 |
| --- | --- |
| Flat、Material、Neumorphismなどの全面的なUIテーマ切り替え | 選択肢の表示はあるが、テーマ全体を切り替える処理は完成していない。 |
| フォント、触覚、学習アルゴリズムなどの設定 | 現在の画面は説明用の表示で、設定値の保存や動作への反映がない。 |
| ウィジェット配置の正式なカスタマイズ | 追加・削除はできるが、配置は再起動後に保存されず、未実装ウィジェットも含まれる。 |
| オフライン学習 | カード、進捗、未送信回答を端末へ永続保存する仕組みがまだない。現在はオンライン接続を前提にする。 |
| 端末の読み上げ音声 | `AVSpeechSynthesizer` は使っていない。配布音声がないカードを端末音声で補うとは約束しない。 |

## 将来案

| 種類 | 後続課題 | 完了後に決め直すこと |
| --- | --- | --- |
| task | USL-219で決めた読取キャッシュと回答送信待ちを実装する | 機内モード、再起動、再送、認証切れの検証後、オフライン学習を正式掲載する。 |
| idea | ウィジェット配置と利用者設定を永続化する | 保存先、端末間同期、利用可能ウィジェットを決めてから正式掲載する。 |
| idea | 複数のUIテーマをアプリ全体へ適用する | 色だけでなく、背景、カード、文字、アイコンまで一貫して切り替わることを確認する。 |
| poc | 配布音声がない場合の端末TTSフォールバックを試す | 音質、英語ロケール、再生速度、端末差、学習体験を比較して採否を決める。 |
