# 決定｜学習タブのデッキは2Dカルーセルに並べ、空き枠から1つずつ足す

決定日: 2026-09-24

## 決めること

学習タブのデッキ一覧は、傾けて重ねる3Dカルーセルで、右上の「デッキ追加 +」から
ギャラリーを開いていた。ギャラリーでは何個でも続けてダウンロードできた。

## 決めたこと

- **並べ方は2Dカルーセル。** 動き（慣性と止まり方）は音声モードの `AudioCarouselMotion` を
  使い回す。中央のデッキだけ縦に広げ、表紙・名前・進み具合を出す。ほかは細い帯にする。
- **「デッキ追加 +」ボタンは無くす。** 代わりに一覧の先頭と末尾に空き枠を1つずつ置く。
  デッキが無いときは空き枠1つだけ。
- **空き枠をタップするとギャラリーを開く。** 1つダウンロードした時点で学習タブへ戻り、
  選んだ空き枠の側の端へ入れて中央に置く。空き枠1つにつき1デッキ。
- **並び順は端末だけに覚える**（UserDefaults）。削除したデッキのぶんは詰める。
- **学習タブを開いたときは、最後に中央へ置いたデッキから始める。**

## やらないこと

- 並び順のサーバー保存（機種変更や再インストールで並びは元に戻る）
- デッキの途中への差し込みと、並べ替え操作
