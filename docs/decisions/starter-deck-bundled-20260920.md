# 決定｜最初のデッキ（大学受験1000語A）はアプリに同梱する

決定日: 2026-09-20

## 決めること

学習タブに出る公式デッキは、起動後にサーバーから読んだ控え（`remote-decks.json`）だけだった。
そのため入れたての端末では、匿名サインインと教材の取得が終わるまでデッキが0件になり、
未接続のままなら「デッキがありません」で止まった。

## 決めたこと

- **`decks.is_starter` の公式デッキ1つを、サーバーの応答と同じ形でアプリに同梱する。**
  置き場所は `apps/ios-swiftui/UsalingoIOS/Resources/StarterDeck.json`。
- **端末に控えが無いときだけ、同梱分を棚へ出す。** ファイルには書かない。
  取得が成功したらサーバーの控えへ入れ替わる。デッキIDもカードIDもサーバーと同じなので、
  同梱分で答えた記録はそのまま引き継がれ、一覧に同じデッキが二重に出ることもない。
- **書き出しは `scripts/export-starter-deck.sh`。** 教材を更新したら流し直して commit する。
- 2026-09-18 に消した同梱JSON（`Resources/SampleDecks/`、6語ずつ18個の画面確認用）とは別物。
  同梱するのは本番の公式デッキそのもの。

## やらないこと

- 2つ目以降の公式デッキの同梱。ギャラリーからのダウンロードのまま。
- 画像・音声の同梱。未接続のときは文字だけで学習する。
