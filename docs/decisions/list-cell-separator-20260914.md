# 決定｜複数の項目が入るセルは ` /&/ ` で区切る

決定日: 2026-09-14

## 決めること

[意味の行に活用と関連語を収める](senses-hold-forms-and-relations-20260914.md) では、
`01_core_senses` の `synonyms`・`antonyms`・`derivatives`・`collocations`・`related` を
`;` で区切るとした。サンプルデータを決めるにあたり、この区切りを決め直す。

## 決めたこと

**項目どうしは ` /&/ ` で区切る。1項目は `単語 :: 訳 :: 補足` にする。** 訳と補足は省ける。
前の決定の「`;` で区切る」は、この決定で取り消す。

サンプル（`synonyms`）:

```text
make :: 作る :: 最も一般的で「無から有を生み出す」広い意味で使われる /&/ produce :: 生産する :: 工業的または農作物を「作り出す」結果に重点がある /&/ generate :: 生み出す :: 電気・利益・アイディアなどを「発生させる」際に使う
```

## 理由

**アプリがもうこの形を読める。** `WordCard.swift` の `WordSynonym.parse` は、
`/&/` で項目を分け、`::` で単語・訳・補足を分ける。区切りをそろえれば、アプリ側の
読み方を変えずに済む。

**訳や補足に `;` を使える。** 日本語の説明文には区切りに似た記号が入りやすい。
`/&/` は文章にまず出てこない並びなので、とりちがえが起きにくい。

## 影響

- [`source-database-v5.md`](../content/source-database-v5.md) の列の説明とサンプルを書き直す
- 単語・訳・補足の中で `/&/` と `::` を使えない
- 取りこみ（USL-308）は `/&/` で区切り、前後の空白を除いて1要素ずつDBへ入れる
