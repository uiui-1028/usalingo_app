# 実機確認｜初回起動から10枚回答までの通し（USL-285）

確認日: 2026-09-01

実施者: 人間（開発機の iPhone 実機）

対象: `apps/ios-swiftui/` の学習本線。M1（TestFlight配信）の受け入れ確認。

## なぜ確認したか

テストが通ることと、人が使えることは別です。CIのXCTestは通っていましたが、
実機で最初から最後まで触った記録はありませんでした。人へ配る前に、本線を1回
通しました。

## 確認した手順と結果

アプリを削除して入れ直し、「初めて開く人」の状態から確認しました。

| # | 確認したこと | 結果 |
|---|---|---|
| 1 | ホーム画面にアイコンと `Usalingo` の名前が出る | 合格 |
| 2 | 初回起動で、設定画面なしに学習が始まる | 合格 |
| 3 | カードに10枚連続で答えられる | 合格 |
| 4 | アプリを閉じて開き直しても記録が残っている | 合格 |
| 5 | ゲストからアカウントを作ると、記録が引き継がれる | 合格 |
| 6 | 通信を切ったときの見え方が壊れていない | 合格 |

**配信を止める不具合は見つかりませんでした。** そのため、この確認から起票した課題は
ありません。

## 記録していないこと

> [!NOTE]
> 各手順に掛かった**秒数と操作回数は記録していません**。合否のみの報告です。
> 数で見る話は「決定｜配信後に見る指標と、次を決める基準を決める」（USL-279）で
> 何を測るかを決めてから、あらためて取ります。

## この確認で満たしたこと

- USL-285 の受け入れ条件（各手順の結果、止める不具合の有無、確認記録の保存）
- [品質ゲート](../operations/release-quality-gate.md) の「本開発中」の**手動操作**の行を更新した。
  ただし同じ行にある「画像・音声なしの表示」は、教材をまだ投入していないため未確認のまま残している

## この確認に含まれないこと

- App Store Connect へのアップロードと TestFlight での配布（USL-287）
- 本番Supabaseでの利用者A/B/未ログインのRLS確認（USL-261 で別途実施）
- アプリ内の法務・ライセンス表示（USL-255。**まだ未実装**）

## あわせて確認したこと

アイコンは USL-281 で入れた `Icons｜SimpleFlatt` の Default です。実機のホーム画面で
見て、問題ないと判断しました。気になれば `assets/usalingo_iconcomposer/Icons｜Glassmorphism/`
へ差し替えられます。入れ替えるのは画像1枚です。

## 次に効くこと

M1 で残っているのは次の2件です。

1. **USL-255** 法務・ライセンス表示（現在 `blocked`）— 人に配るなら必要
2. **USL-287** TestFlightへの提出と内部テスターへの配布

USL-287 は USL-285 と USL-255 の両方が終われば着手できます。
