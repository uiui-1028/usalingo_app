# 決定｜シートのIDはゼロ埋めしてもよい

決定日: 2026-09-14

## 決めること

[シートのIDは頭文字を付けず、これまでどおり数字にする](sheet-id-keep-numbers-20260914.md) では
「ゼロ埋めはしない」とした。しかしシートのIDは `0001` の形のまま、文字として入っている。
シートを直すか、ルールを変えるかを決める。

## 決めたこと

**シートのIDは `0001` でも `1` でもよい。取りこみ（USL-308）が整数に直す。**
DBの整数IDとStorageパスの数字は `1` になる。

## 理由

**意味は同じで、読みかえは取りこみが1か所でできる。** `0001` と `1` は同じ番号である。
取りこみはどのみち数字として読むので、1000行以上を書き直す手間とまちがいを避けられる。

## 影響

- [`source-database-v5.md`](../content/source-database-v5.md) のIDの形の説明を直す
- 取りこみは、数字だけでできていないIDを見つけたら全体を止める
- 整数に直したあとで同じ番号が2つある（`01` と `1` など）場合も、重複として止める
