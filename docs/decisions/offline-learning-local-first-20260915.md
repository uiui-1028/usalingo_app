# 決定｜学習は端末を先に使う

決定日: 2026-09-15

## 背景

起動時のSupabase匿名サインインに失敗すると、端末内に教材と学習機能があっても
全画面のエラーが表示され、学習できなかった。Wi-FiやSupabaseの状態にかかわらず
ローカルで学習できることが、新しい要件として明示された。

## 決めたこと

- 学習画面は認証処理を待たずに開く。
- デッキ、学習キュー、回答、Undo、タグ、単語編集、統計は
  `LocalStudyDataSource` を入口にする。
- Supabase Authの失敗は学習を止めない。
- 通信失敗では保存済みセッションを消さず、通信復帰後に再利用する。
- 接続できない間は「オフラインで学習中」と表示する。

これは [ゲストを「匿名アカウント」にする](guest-is-an-anonymous-account-20260907.md) の
「学習の正本をSupabaseに置き、接続失敗時は学習を止める」という部分を置き換える。
匿名アカウントを会員登録へ育てる仕組みは残す。

## 境界

- 登録済みアカウントの既存バックアップ動作は変えない。
- 匿名アカウントの端末データをSupabaseへ新しく送らない。
- 2026-09-17の明示確認に基づき、退会成功時にだけ端末の学習履歴、タグ、
  単語編集、追加教材を削除し、初期教材へ戻す。退会失敗時には削除しない。
- 画像・音声キャッシュは削除対象に含めない。
- Supabaseの公式教材を端末へ更新する処理は、別ブランチで扱う。
- 取得済みでない画像や音声は、オフライン時に表示・再生できるとは保証しない。
