# 決定｜デッキ追加はSupabaseの公式デッキから選ぶ

決定日: 2026-09-18

## 決めること

「デッキを追加」のギャラリーには、アプリに同梱した試し用のJSON（6語ずつ18個）が
並んでいた。Supabaseの公式デッキ（大学受験1000語A〜J）とは別物で、ログイン中に
追加しても、ほとんどの単語がSupabaseに無いため入らなかった。
また、ログインすると公式デッキ10個がすべて学習タブに並んでいた。

## 決めたこと

- **正本はSupabaseの公式デッキ。** ギャラリーはサーバーの公式デッキを読む。
- **最初に学習タブへ出す公式デッキは「大学受験1000語A」だけ。** `decks.is_starter` で示す。
- **ほかの公式デッキは、ギャラリーからダウンロードして追加する。** 追加の記録は
  `user_added_decks` に本人ごとに残す。
- **同梱JSON（`Resources/SampleDecks/`）は消す。** 画面確認用のテストデータだった。
- **ギャラリーのジャンルは当面「受験」だけ。** 「英語・日本語」の分類はやめる。
- すでに学習記録がある公式デッキは、追加済みとして扱う（移行で記録を作る）。

## やらないこと

- 学習タブから公式デッキを外す操作
- 学習タブの進み具合に出ている作り物の数字（`DeckDisplaySample`）の置き換え。別チケットで扱う
