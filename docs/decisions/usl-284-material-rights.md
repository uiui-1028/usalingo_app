# USL-284 配る素材の権利と表示条件

決定日: 2026-09-01

対象: `docs/content/anki-50-extraction.md` で確定した、Ankiデッキ「TARGET-1900」由来の最初の50語（画像150件、単語音声・例文音声を含む）

## 背景

このリポジトリと過去のNotion記録だけでは、50語で使う単語リスト・日本語訳・例文・イラスト・音声の
作成方法を確認できなかった。原本はユーザーのローカルAnki環境にあり、AIエージェントからは中身を
読めない。特に「TARGET-1900」という名称は旺文社の市販書籍『英単語ターゲット1900』を想起させ、
出どこが不明なまま「たぶん大丈夫」で通すことはこの課題で禁止されている。そのため作成者本人
（河合泰芽）に直接確認した。

## 確認した内容（作成者本人からの回答）

| 対象 | 作成方法 | 使用サービス | 契約形態 |
|---|---|---|---|
| 単語選定・日本語訳・例文（英文/和訳） | 当方が独自作成 | ChatGPT（OpenAI） | — |
| イラスト（例文画像、WebP変換前の原本） | 当方が独自作成 | Midjourney | 有料プラン（Basic以上のサブスクリプション） |
| 音声（単語発音・例文読み上げ） | 当方が独自作成 | Google Cloud Text-to-Speech API | 有料・GCPプロジェクト経由（公式API） |

第三者が公開する単語リスト（NGSL、NAWL、旺文社の市販書籍など）からの転記・参照は**ない**。
`docs/legal/published/credits.md` 第3節がすでに記録しているTOEIC頻出100語（生成AI作成、当方に帰属）
と同じ性質の素材であり、その行と矛盾しない。

## 各サービスの利用条件（確認済み）

- **OpenAI（ChatGPT）**: 利用規約上、出力（Output）の権利はOpenAIからユーザーへ譲渡され、商用利用を含む
  利用が認められている。第三者が同一の出力を生成した場合にそれを止める著作権は成立しない可能性がある点は
  留意事項として記録する。
- **Midjourney**: 有料サブスクリプション（Basic以上）は "General Commercial Terms" の対象であり、
  生成した画像（Assets）の商用利用が認められている。年間売上100万USD超の企業はPro/Mega契約が必要という
  条件があるが、Usalingoの現状はこれに該当しない。無料トライアルでの生成は商用利用不可のため対象外。
- **Google Cloud Text-to-Speech API**: 公式APIの利用であり、生成音声の商用利用は認められている。
  ただし「1リクエストにつき1エンドユーザー向けにその場で生成する」用途と、「生成済み音声を配布用ライブラリ
  として再配布・バンドルする」用途では扱いが異なる可能性があるとする外部解説がある。Usalingoの配り方
  （USL-283の決定：Supabase Storageへ事前生成した音声ファイルを置き、多数の利用者へ配信する）は後者に近い。
  本番Storageへ実際にアップロードする前に、Google Cloudの商用利用条件を規約原文で再確認することを
  残課題とする（下記「使えない場合の差し替え方針」参照）。

## 表示が必要なものと、その出し場所

- OpenAI・Midjourney・Google Cloud TTSのいずれも、エンドユーザー向け画面への著作権表示（クレジット）を
  利用規約上は義務付けていない。CC BY-SA等の継承ライセンス素材（NGSL等）とは異なり、表示義務は生じない。
- 一方でUsalingoは透明性のため、`docs/legal/published/credits.md` 第3節（単語リストの出典）・第4節
  （イラスト・音声の出典）に「当方が生成AIを用いて作成」の形で記録する方針をすでに採用している
  （第3節のTOEIC100語の行と同じ体裁）。**表示先はアプリ内「プロフィール → 法務・ライセンス → クレジット」
  画面**（`LegalInformationView` が `credits.md` を表示する既存の仕組み。新規UIは不要）。
- credits.md 自体の更新は、実際に50語のイラスト・音声を本番Storageへ配信し始める時点（USL-288以降）で
  行う。現時点では「現在配信している学習コンテンツに、イラストおよび音声は含まれていません」という記載が
  事実と一致しているため、先取りして書き換えない。配信開始時に追記する文言案は次のとおり。

  ```markdown
  | TARGET-1900由来の例文・イラスト・音声（50語） | 当方が生成AIを用いて作成（例文・訳: ChatGPT / イラスト: Midjourney / 音声: Google Cloud Text-to-Speech） | 当方に帰属 | 第三者の単語リスト・書籍からの転記はありません |
  ```

## 使えない素材があれば、差し替え方針

現時点で50語・150 media（`docs/content/anki-50-extraction.md` の検査結果: media存在確認 150/150）は
いずれも作成者本人による生成AI利用と確認でき、差し替えが必要な素材は**ない**。

ただし次の場合は本番投入（USL-288）前に差し替えを検討する。

| 条件 | 差し替え方針 |
|---|---|
| Google Cloud TTSの商用条件が「事前生成した音声の再配布用バンドル」を許可しないと規約原文で確認された場合 | VOICEVOX等、静的配布を明示的に許可する音声合成サービスで対象音声を再生成する。個々のvoice/キャラクターのクレジット表示義務があれば、上記credits.md追記案にその条件を反映する |
| 将来Midjourneyの契約プランが無料トライアルへ変わった、または年間売上が100万USDを超えてPro/Mega契約が必要になった場合 | 該当プランへ契約を切り替えるか、商用利用可能な別サービスでイラストを再生成してから配信する |
| 個別の単語・例文にNGワード等ブランド不適合な内容が見つかった場合 | 該当語のみChatGPTで再生成し、`docs/content/anki-50-extraction.md` の検査結果を更新する |

## 今回は含めないこと

- 弁護士による法的判断（OpenAI/Midjourney/Google Cloudの規約解釈の最終確認）
- 利用規約・プライバシーポリシーの全面改訂
- 50語の本番Storageアップロード・DB投入（USL-288、別途承認が必要）
- `docs/legal/published/credits.md` の本文書き換え（配信開始時に別途実施）

- 台帳（`docs/legal/asset-and-privacy-inventory.md` 第5節）と、この決定記録の内容が一致することを確認した。
- 作成方法・使用サービス・契約形態は、作成者本人（Notionワークスペースの認証ユーザー taiga_kawai、
  taiyahehe@gmail.com）への確認により確定した。ローカルAnki原本ファイルそのものの検査は対象外。
