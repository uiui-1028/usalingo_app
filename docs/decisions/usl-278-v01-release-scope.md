# USL-278 v0.1で配るものと配らないもの

決定日: 2026-09-01

対象: M1（身内テスターがTestFlightでUsalingoを触れる）で配る最初の内部テスト版。

## 結論

v0.1は、**現在の同梱教材で学習の本線を先に配り、50語の正式教材を待たない**。
学習、ゲスト利用、回答記録、任意のアカウント作成と記録の引き継ぎは入れる。
一方、将来向けのデザイン機能と、正しい履歴を出せない統計は画面に出さない。

この線は、M1の配信経路を先に通し、M2で教材の質と量を上げるためのものとする。

## 入れるものと入れないもの

| 対象 | v0.1の判定 | 内容・理由 | 見直すとき |
|---|---|---|---|
| 学習の本線 | **入れる** | 初回起動から設定画面なしで学習を始め、10枚に答え、記録を残せることをM1の中心にする | 内部テスターが10枚まで進めない、または3分を超える人が複数出たとき |
| ゲスト開始 | **入れる** | 登録を先に求めず、初めて開いた人がすぐ学べることは製品計画とUSL-247の決定に合う | 内部テストで記録消失や開始不能が見つかったとき |
| アカウント作成 | **入れる（任意）** | 学習前には求めず、学習後に必要な人が作れるようにする | 登録が学習の邪魔になるという反応が出たとき |
| ゲスト記録の引き継ぎ | **入れる** | アカウント作成で、それまでの学習記録を失わせない | 引き継ぎ失敗が実機または本番環境で見つかったとき |
| 教材 | **現在の同梱教材で先に配る** | M1は配信経路と10枚の学習を確認する段階。50語の正式教材を待つとM1とM2の順番が逆になる | M2で50語の正式教材が実機へ通ったとき |
| プロフィール | **必要部分だけ入れる** | アカウント、記録の引き継ぎ、バックアップ、法務・問い合わせへの導線に使う | M1の必須導線が別の場所へ移ったとき |
| デザインタブ | **入れない** | 見た目や学び方を組み立てる機能は製品計画で将来機能。M1の10枚学習には不要 | M1配信後に利用者の反応を確認したとき |
| ヒートマップと学習日数 | **表示しない** | `user_card_progress.last_reviewed_at` はカードごとの最後の1回しか残さず、過去の学習日を正しく表せない。「参考値」として誤った数字を配る案も採らない | 正しい履歴テーブルと集計を実装・検証したとき |
| 旧AppStyle画面 | **入れない** | 現行のSwiftUIアプリとM1の本線に含まれない | 現行デザインへ移す必要が具体化したとき |
| オフライン対応 | **入れない** | M1・M2の完了に必須ではない。実機確認で通信を切った際に画面が壊れないことは確認済みだが、完全なオフライン学習を保証した意味ではない | 内部テスターから実際の要望が出たとき |
| 正確な統計 | **入れない** | M1後の指標はUSL-279に従って手で集めるため、アプリ内集計は不要 | 内部テスト後、集計を自動化する価値が確認できたとき |

## 学習の本線

v0.1で守る流れは次のとおり。

```text
アプリを開く
→ 設定なしでゲストとして学ぶ
→ カードに答える
→ 記録が端末に残る
→ 必要な人だけアカウントを作る
→ ゲストの記録を引き継ぐ
```

学習前の設定画面、アンケート、復習か新規かを利用者に選ばせる画面は足さない。
2回目以降は、学習タブのデッキをタップすると確認画面なしで学習を始める。

## 配信前に必要な反映

この文書は範囲を決めるもので、画面変更そのものは行わない。USL-287でTestFlightへ提出する前に、
別の実装作業として次を満たす必要がある。

1. デザインタブをv0.1の利用者へ表示しない。
2. プロフィールからヒートマップ、学習日数、正確さを保証できない統計を表示しない。
3. プロフィールに残すアカウント、引き継ぎ、バックアップ、法務・問い合わせ導線が到達できることを確認する。

実装とテストの証拠がないまま、この決定だけで「配信可能」とは扱わない。

## 今回は含めないこと

- 上で決めた表示変更のコード実装
- 50語の正式教材、画像、音声の投入
- TestFlightへの提出、App Store一般公開
- 本番Supabase、Auth、Storageの変更
- 解析SDKまたは自動集計の導入

## 理由

- M1は配信の管を先に通し、M2は正式教材を50語まで通すという順番で決められている。
- USL-285の実機確認では、初回起動、10枚回答、記録保存、ゲストからアカウントへの引き継ぎが合格している。
- 事実と違う学習履歴は、機能が少ないことより危険である。正しくできるまで表示しない。
- デザイン、オフライン、統計を後へ回すことで、内部テスターから得たい「10枚学べるか」という答えをぼかさない。
