# Quizlet 競合調査

> [!NOTE]
> **公式Web調査日: 2026-08-24 / 実機メモ統合日: 2026-08-27**

## 公式情報で確認できたこと

- Flashcardsは、ログイン→セットを開く→モードを選ぶ→カードをめくる→スワイプで次へ進む。
- `Know / Still learning` への分類、並べ替え、表裏の向き、音声などを設定できる。
- Learnは、セットを開き、学習目標を選んで始める。目標や理解度から学習経路を調整する。
- FlashcardsとLearnなど複数の学び方があり、利用者がモードを選ぶ。

## 1問の流れ

### Flashcards

```text
セット
→ Flashcardsを選ぶ
→ カード表面
→ タップして裏面
→ スワイプ
→ 次のカード
```

- 必要なら `Still learning / Know` への分類を有効にできる。
- 全カードを見ると1ラウンド終了になる。

### Learn

```text
セット
→ Learn
→ 学習目標を選ぶ
→ 学習開始

問題
→ 回答
→ 正誤等を記録
→ 目標と理解度に応じて以降の経路を調整
→ 次の問題
```

> [!NOTE]
> 「個別の学習経路」はQuizlet運営による機能説明です。第三者が学習効果を検証した事実としては扱いません。

> [!IMPORTANT]
> **Usalingoへの仮説:** カードをめくって連続する軽い操作は参考になる。一方、セット・モード・目標の選択は最初の学習前には置かない。
