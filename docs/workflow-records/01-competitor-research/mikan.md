# mikan 競合調査

> [!NOTE]
> **公式Web調査日: 2026-08-24 / 実機メモ統合日: 2026-08-27**

## 公式情報で確認できたこと

- 4択は、教材→開始→学習設定→モード→英日・日英・リスニングを選んで進む。
- カード学習は、覚えたら右、分からなければ左へスワイプする。
- 分からない単語を繰り返し、カード学習後にテストを案内する。
- 問題数、音、制限時間などを設定できる。
- 公式サイトは「1単語3秒、10単語30秒」という速い学習を訴求している。

## 2026年の実機メモ

### カード学習

```text
教材
→ 「はじめる」または「前回の続き」
→ 学習設定
→ カードを選択

英単語
→ タップして日本語訳を表示
→ 覚えたなら右 / 分からないなら左
→ 次のカード

設定した語数まで終了
→ 「テストする」の案内
→ 次の学習を選ぶ
```

- 設定によって日本語訳を自動表示できるため、全利用者が必ず答えを思い出す時間を取るわけではない。

### 4択学習

```text
英単語などの問題
→ 4択で回答
→ 正誤を記録
→ 習熟度を更新
→ 次の問題
```

- 習熟度は「苦手 / うろ覚え / ほぼ覚えた / 覚えた」の4分類。
- 復習は低い習熟度を優先し、同じ習熟度では学習履歴が古い語から出題される。

> [!NOTE]
> mikanは、利用者の回答操作を簡単にしながら、裏側にはより細かな学習状態を持つ競合である。

### 画面全体

- 主なタブは、教材一覧、コーチ、学習データ、マイページの4つ。
- 教材一覧は絵付きで情報量が多い。利用中の教材を常時表示し、別教材を後から追加する構成は参考になる。
- コーチは英語レベル診断や学習案内であり、Usalingoでは採用しない。
- 学習前の操作と学習後の結果表示は多く、認知負荷が高く感じられた。
- 学習データとマイページは分離されているが、Usalingoで同じ分け方を採る理由は見つからなかった。

> [!IMPORTANT]
> **Usalingoへの仮説:** 1問を迷わず判定して連続できる速さは参考になる。教材・モード・出題方向・詳細設定を毎回選ばせる流れは採らない。

> [!TIP]
> **追加の示唆:** 自分が使うデッキだけを一覧へ常時表示し、それ以外は追加する方式を採る。学習前後の情報はAnkiに近い水準まで減らす。
