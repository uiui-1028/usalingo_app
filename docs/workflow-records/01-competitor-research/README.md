# 競合4アプリのWeb比較

> [!IMPORTANT]
> **調査日: 2026-08-24**。これは公式Web情報から作った比較と仮説です。実際の初回画面や細かなタップ順は、アプリの版や利用状態で変わるため未確認です。

## 先に分かったこと

| アプリ | 学習前に選ぶもの | 1問の中心 | 次のカード |
|---|---|---|---|
| Anki | デッキ、学習開始 | 問題→答えを見る→4段階評価 | 期限と評価から自動選択 |
| Quizlet | セット、モード。Learnでは目標 | カードをめくる、または複数形式の問題 | モードに応じて進行 |
| TANZAM | 単語帳、学習モード | イラスト・例文・音声を使った学習 | 忘却曲線に沿って自動出題 |
| mikan | 教材、モード、出題方向、設定 | 4択、またはカードを左右へ分類 | 不明語を反復し、学習後にテスト案内 |

> [!TIP]
> 共通点は「カードを自動で次へ進めること」です。違いは、**学習を始める前に利用者へどれだけ選ばせるか**です。

## Usalingoの初期仮説

### H1：ホームの主ボタンは、そのまま学習開始

> [!IMPORTANT]
> おすすめ仮説です。デッキ、復習／新規、学習モード、問題数を先に選ばせず、アプリが前回の記録から次のカードを決めます。

- 根拠: 4社には学習前の選択があるが、Usalingoの方針は「迷わずすぐ学ぶ」。
- 採るもの: AnkiとTANZAMの自動出題。
- 採らない候補: Quizletの目標選択、mikanの毎回の学習設定。
- 未確認: 初回だけ必要な教材ダウンロードや同意画面の扱い。

### H2：1問は「思い出す」と「理解する」を分ける

> [!NOTE]
> `英単語とイラストを見る → 意味を思い出す → 答え・例文・音声を見る → 覚えやすさを評価する` を仮の一本とします。

- Ankiから採る: 答えを見る前に思い出す時間と、回答後の自己評価。
- TANZAMから採る: イラストと例文を一つの記憶として扱うこと。
- mikanから採る候補: 迷わず連続できる単純な操作。
- 未決定: イラストを問題側と答え側のどちらで見せるか。

### H3：評価は簡単に見せ、裏側はAnki型を保つ

> [!WARNING]
> ボタン数はまだ決定しません。Ankiは4段階評価を基本としつつ、公式マニュアルでは `Again` と `Good` の2ボタン運用も案内しています。

- 案A: 4段階を、やさしい日本語で表示する。
- 案B: 最初は「もう一度／覚えた」の2つを見せる。
- 決める基準: 学習精度を壊さず、初めての人が迷わないこと。

### H4：学習終了は止めず、区切りだけ伝える

> [!NOTE]
> 今日の予定分が終わったら成果を短く示し、「終わる」を主に、「もう少し」を副に置く仮説です。

- 根拠: Ankiは予定カードが尽きるまで進み、TANZAMは1日の新規語数を設けています。
- 未確認: 競合の終了画面と、翌日の再開位置。

## 人が確認するなら、この3点だけ

> [!TIP]
> 4アプリすべての詳細レポートは不要です。最も近いTANZAMだけ、次を5〜10分確認すれば仮説の精度が上がります。

1. 初回起動から最初の問題までに選ぶ項目。
2. 1問で、イラスト、例文、意味、評価が現れる順番。
3. 10語終了後と翌日の再開画面。
