# 最短成功フロー

> [!IMPORTANT]
> **状態: 2026-08-27決定済み**。初回と2回目以降の入口だけを分け、学習中は同じ一本の流れを使います。

## 変えない条件

- 利用者に、復習か新しいカードかを選ばせない。
- 次のカードは、2段階SM-2ハイブリッドでアプリが自動決定する。
- 学習前の不要な説明、設定、画面移動を置かない。
- イラスト付き英単語で「分かった！」を感じられることを中心にする。

## 初回の入口

```text
アプリを開く
→ ゲストとして始める
→ アンケートなし
→ 初回だけ操作ヒント
→ 標準デッキを自動設定
→ 学習開始
```

## 2回目以降の入口

```text
アプリを開く
→ デッキ一覧
→ デッキをタップ
→ 設定画面なしで学習開始
```

## 決定した学習の一本

```text
SRSが次のカードを出す
→ 利用者が考える
→ 答えを見る
→ 内容を自分の時間で確認する
→ 右スワイプで正解／左スワイプで不正解
→ 回答と次回復習日を保存
→ 次のカード、またはComplete
```

答えを表示しただけでは次へ進みません。途中で離れた場合は中断として保存し、現在出題可能なカードが0枚になった場合だけCompleteとします。

## 各手順をなくせない理由

- 初回の自動設定は、選択をなくして最初の学習へ早く届けるため。
- 2回目以降のデッキ一覧は、学びたい公式デッキを選べるようにするため。
- 答えを見る工程は、自分で思い出す時間と内容確認の時間を分けるため。
- 左右スワイプは、正解／不正解を迷わず入力するため。
- 回答ごとの保存は、中断や通信失敗で学習記録を失わないため。
