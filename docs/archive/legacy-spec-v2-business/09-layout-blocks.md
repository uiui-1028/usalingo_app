## ***【 usalingo_03_03｜レイアウト & ブロック定義 】***

*主要な各タブ画面を構成する機能単位「ブロック」の種類と仕様を定義し、ユーザーが自身の学習スタイルに合わせてカスタマイズできる設定項目を網羅的に定める。*

---

## ✦ **タブ別ブロック定義**

*本セクションでは、各主要タブに配置可能な「ブロック」の種類と、その機能仕様を定義する。ユーザーはこれらのブロックを自由に組み合わせることで、自らの学習環境を構築する。*

---

### **✦ 学習タブ**

 *日々の学習を行うための、インタラクティブなブロックを配置するエリア。ユーザーはここに学習したいテーマのデッキを配置し、アプリ起動後すぐに学習を開始できる。*

---

### **● 学習デッキブロック (Learning Deck Block)**

 *Ankiのデッキ思想を基盤とした、usalingo の中核となる学習ブロック。新規カードの学習から忘却曲線に基づいた復習まで、全ての学習活動をこのブロック内で完結させる。*

```yaml
.block-learning_deck {
  name: "学習デッキブロック"
  description: "新規・復習カードを統合管理する、単語学習のコア機能。ユーザーはデッキごとに学習方法や範囲を柔軟に設定できる。";
  
  core_interaction:
    - name: 即時学習スタート"
      trigger: ブロック本体のタップ。"
      action: 最後に保存された設定で、即座に学習セッションを開始する。"
      
    - name: 学習設定の編集"
      trigger: "ブロック内の編集アイコンをタップ。"
      action: "学習設定用のボトムシートが開き、セッション内容をいつでも手軽に変更できる。"
      
  customizable_options:
    description: "ブロックの編集アイコンから設定可能なカスタマイズ項目。ユーザーによる設定内容は永続化され、次回起動時にも維持される。";
    
    - setting_key: "session_size"
      type: "INTEGER"
      description: "1回の学習セッションで出題するカードの上限枚数。"
      constraints: "min: 5, max: 100" # 範囲を指定
      default_value: 20

    - setting_key: "card_order"
      type: "TEXT"
      description: "カードの出題順。"
      constraints: "enum: ['random', 'sequential']" # 利用可能な値を列挙
      default_value: "random"
      
    - setting_key: "new_cards_per_day"
      type: "INTEGER"
      description: "1日に学習する新規カードの上限枚数。"
      constraints: "min: 0, max: 200" # 範囲を指定
      default_value: 10
      
    - setting_key: "review_cards_per_day"
      type: "INTEGER"
      description: "1日に復習するカードの上限枚数。"
      constraints: "min: 0, max: 500" # 範囲を指定
      default_value: 50
      
    - setting_key: "learning_mode"
      type: "TEXT"
      description: "学習の形式。"
      constraints: "enum: ['flashcard', 'quiz']" # 利用可能な値を列挙
      default_value: "flashcard"
      
    - setting_key: "study_approach"
      type: "TEXT"
      description: "学習セッションのアプローチを選択する。"
      constraints: "enum: ['standard_srs', 'free_study']" # '標準SRS学習'と'フリー学習'
      default_value: "standard_srs"
      
    - setting_key: "scope"
      type: "JSONB"
      description: "学習範囲の指定オブジェクト。typeキーで'all' (全体) または 'chapters' (特定章) を指定。"
      constraints: "type_enum: ['all', 'chapters']" # 利用可能な型を列挙
      default_value: '{"type": "all"}'
}
```

    - action_key: "repeat_audio"
      name: "音声リピート"
      icon: "replay_icon"

    - action_key: "go_back"

    - action_key: "toggle_favorite"

### **✦ デザインカスタマイズタブ**

 *アプリ全体のUI/UX（見た目、操作感、フィードバック）をユーザーの好みに合わせて調整するための設定項目群を配置するエリア。これらはブロックではなく、タブ内に直接配置される設定モジュール。*

---

### **● UIテーマ設定モジュール**

 *アプリ全体のデザインシステム、カラーモード、アクセントカラーを包括的に変更する。*

```yaml
.module-ui_theme {
  name: UIテーマ設定モジュール;
  description: "アプリ全体のルック＆フィールを、ユーザーの美的感覚に合わせて根本から調整する。この設定は、ホーム画面のアプリアイコンにも自動的に反映される。";
  customizable_options:
    ------------------------------------
    - name: デザインスタイル
      description: "アプリのUIデザインの基本スタイルを選択する。選択したテーマに基づき、ホーム画面のアプリアイコンも連動して変更される。（例：Glassmorphism選択時、アイコンもガラスのようなデザインに変わる）"
      options:
        - FlatDesign（デフォルト）
        - Neumorphism
        - Glassmorphism
        - MaterialDesign
    ------------------------------------
    - name: カラーモード
      description: 表示モードを切り替える。
      options:
        - ライトモード
        - ダークモード
        - システム設定に追従（デフォルト）
    ------------------------------------
    - name: アクセントカラー
      description: ボタンやアクティブな要素に使われる差し色を、運営が用意したカラーパレットから選択する。
      options:
        - ピンク（デフォルト）
        - プリセットカラー
}
```

### **● カードUI設定モジュール**

 *学習カードに表示する情報（語源、イラスト等）の ON/OFF や、操作モード（パンチ / 裏返し）を切り替える。*

```yaml
.module-card_ui {
  name: カードUI設定モジュール;
  description: 学習カードの表示要素や操作方法をカスタマイズし、個々のユーザーにとって最も集中しやすい情報レイアウトを実現する。;
  customizable_options:
    ------------------------------------
    - name: 情報表示設定
      description: カード上に表示するデータ項目をON/OFFで切り替える。
      options:
        - 単語訳
        - 単語音声
        - 発音記号
        - 例文
        - 例文訳
        - 例文音声
        - 品詞
        - 語源
        - 類義語
        - 対義語
        - イラスト
				- 多義語の表示
	        - 全ての意味を表示（デフォルト）
	        - 主要な意味のみ表示
    ------------------------------------
    - name: 解答インタラクション
      description: 解答を表示する際の操作方法を選択する。
      options:
        - パンチアクション（タップで表示）
        - カード裏返し（スワイプまたはタップで反転）
}
```

### ● アルゴリズム設定モジュール

 *忘却曲線アルゴリズムの挙動を、ユーザーの学習スタイルや目的に合わせて詳細に調整するための設定項目。*

```yaml
.module-algorithm_settings {
  name: "アルゴリズム設定モジュール";
  description: "日々の学習ペースや復習の間隔など、記憶の定着を司るアルゴリズムの核心部分をカスタマイズする。Ankiのように、学習者自身が最適な学習効率を追求できる。";

  customizable_options:
    description: "Ankiの思想を参考にしつつ、usalingoの思想に合わせて項目を厳選・簡略化したパラメータ群。";
    
    - setting_key: "new_cards_per_day"
      name: "1日の新規カード枚数"
      type: "INTEGER"
      description: "1日に学習する新しい単語の上限枚数。"
      default_value: 20
      
    - setting_key: "graduating_interval"
      name: "卒業間隔"
      type: "INTEGER"
      description: "新規カードを初めて『わかる』にした後、次に復習するまでの日数。"
      default_value: 1

    - setting_key: "easy_interval"
      name: "簡単なカードの間隔"
      type: "INTEGER"
      description: "学習中のカードを『簡単』だと評価した場合の、次の復習までの基本日数。"
      default_value: 4
      
    - setting_key: "interval_modifier"
      name: "間隔の乗数"
      type: "PERCENTAGE"
      description: "アルゴリズムが算出した全ての復習間隔に適用される全体的な倍率。"
      default_value: "100%"
      
    - setting_key: "maximum_interval"
      name: "最大間隔"
      type: "INTEGER"
      description: "復習間隔がどれだけ長くなっても、この日数を超えることはないようにする上限値。"
      default_value: 365
}
```

 *連続学習記録を表示し、日々の学習継続を視覚的にサポートする。*

## ✦ 学習**パーソナライズ設定**

本セクションでは、ユーザーが自身の学習スタイルや好みに合わせてアプリケーションを最適化するための、全てのカスタマイズ項目を網羅的に定義する。設定は、デッキごとに適用される「学習デッキ設定」と、アプリ全体に適用される「グローバル設定」に大別される。

---

### ✦ **学習デッキ設定**

*学習タブの各デッキブロックから呼び出されるボトムシートで、セッションごとに変更可能な設定項目。*

---

### **● 学習アプローチ**

*学習セッションでどのカードを、どのようなロジックで出題するかを定義する、中核的な学習方法。*

| 選択肢 | 概要 | デフォルト |
| --- | --- | --- |
| 標準SRS学習 | 忘却曲線アルゴリズム（SM-2等）に基づき、長期記憶に最適なタイミングで復習カードを自動的に提示します。日々の学習進捗は記録・更新されます。 | ✔️ |
| フリー学習 | アルゴリズムに縛られず、デッキ内のカードを自由に学習できます。このモードでの学習結果は、既存の学習進捗データに一切影響を与えません。 試験前の総復習や、空き時間での気軽な見返しに最適です。 |  |

---

### ● 学習スコープ

*そのセッションで出題されるカードの範囲を絞り込む。*

| 選択肢 | 概要 | デフォルト |
| --- | --- | --- |
| **全てのカード** | デッキ内の全カードを対象とする。 | ✔️ |
| **章・タグで絞り込む** | 特定の章や、ユーザーが付与したタグ（例：「苦手」「要復習」）を持つカードのみを対象とする。 |  |

---

### ● 学習モード

*そのセッションで出題されるカードの種類を選択する。*

| 選択肢 | 概要 | デフォルト |
| --- | --- | --- |
| **通常学習** | 新規カードと復習カードを混ぜて学習する。 | ✔️ |
| **新規学習のみ** | まだ一度も学習していないカードのみを学習する。 |  |
| **復習のみ** | 既に学習済みのカードのみを復習する。 |  |

---

### ● セッション設定

*1回の学習量や1日の上限を設定する。*

| パラメータ | 概要 | UIコンポーネント | 範囲 / 値 | デフォルト |
| --- | --- | --- | --- | --- |
| **1回の学習セッション** | 1セッションで出題されるカードの上限枚数。 | スライダー | 5〜100 (5刻み) | 20 |
| **1日の新規カード** | 1日に学習する、新しい単語の上限枚数。 | スライダー | 0〜200 (5刻み) | 10 |
| **1日の復習カード** | 1日に復習するカードの上限枚数。 | スライダー | 0〜500 (10刻み) | 50 |

---

### ✦ **学習アルゴリズム設定**

---

### ● 基本設定

*学習体験の根幹をなすアルゴリズムと思想を選択する。*

| パラメータ | 概要 | UIコンポーネント | 選択肢 | デフォルト |
| --- | --- | --- | --- | --- |
| **学習アプローチ** | 単語の学習単位を定義する。 | セグメントコントロール | 一語多義, 一語一義 | 一語多義 |
| **アルゴリズムタイプ** | 復習間隔を計算するためのアルゴリズム。 | ドロップダウン | Spaced Repetition (SM-2), Leitner System | SM-2 |

---

### ● 新規カードの学習ステップ

*新しい単語を記憶に定着させるまでの、初期の復習間隔を設定する。（Ankiの学習ステップに相当）*

| パラメータ | 概要 | UIコンポーネント | 範囲 / 値 | デフォルト |
| --- | --- | --- | --- | --- |
| **学習ステップ** | 「わからない」を押した後、次に表示されるまでの時間。カンマ区切りで複数設定可能。 | テキスト入力 | (例) 10m, 1h, 12h | 10m, 1d |
| **初回卒業間隔** | 全ての学習ステップを完了したカードが、初めて復習カードになるまでの日数。 | スライダー | 1日〜14日 | 3日 |

---

### ● 復習カードの間隔調整

*復習カードの表示頻度を詳細にコントロールする。*

| パラメータ | 概要 | UIコンポーネント | 範囲 / 値 | デフォルト |
| --- | --- | --- | --- | --- |
| **間隔の乗数** | 全ての復習間隔に適用される全体的な倍率。 | スライダー | 50%〜250% | 100% |
| **最大間隔** | 復習間隔の上限値。 | スライダー | 30日〜1000日 | 365日 |
| **忘却時の再学習間隔** | 復習カードを「わからない」と評価した際、新しい復習間隔を元の間隔の何%にするか。 | スライダー | 0%〜100% | 25% |

### ✦ **UI デザイン設定**

---

### ● デザインスタイル

*アプリ全体のUIデザインの基本スタイルを選択する。*

| 選択肢 | 概要 | デフォルト |
| --- | --- | --- |
| **Flat Design** | 立体感や過度な装飾を排した、シンプルで機能的なデザイン。 | ✔️ |
| **Neumorphism** | 背景と一体化したような、凹凸で表現されるミニマルなデザイン。 |  |
| **Glassmorphism** | すりガラスのような半透明のレイヤーを重ねる、軽やかでモダンなデザイン。 |  |
| **Material Design** | Googleが提唱する、物理法則に基づいた直感的なデザイン。 |  |

---

### ● カラーモード

*アプリの表示モードを切り替える。*

| 選択肢 | 概要 | デフォルト |

| **ライト** | 明るい背景色をベースとした標準的なモード。 |  |
| **ダーク** | 暗い背景色をベースとし、目への負担を軽減するモード。 |  |

### ✦ **アプリ挙動設定**

---

### ● 音声フィードバック

*単語や例文の読み上げに関する挙動を設定する。*

| パラメータ | 概要 | UIコンポーネント | 選択肢 | デフォルト |
| --- | --- | --- | --- | --- |
| **自動再生** | カード表示時に音声を自動再生するか。 | トグルスイッチ | ON / OFF | ON |
| **音声アクセント** | 読み上げ音声のアクセント。 | ドロップダウン | アメリカ英語, イギリス英語 | アメリカ英語 |
| **音声の性別** | 読み上げ音声の性別。 | セグメントコントロール | 女性, 男性 | 女性 |
| **再生速度** | 読み上げ音声の再生速度。 | セグメントコントロール | 0.75x, 1.0x, 1.25x | 1.0x |

---

### ● 触覚・効果音フィードバック

*操作時の物理的なフィードバックを設定する。*

| パラメータ | 概要 | UIコンポーネント | 選択肢 | デフォルト |
| --- | --- | --- | --- | --- |
| **触覚フィードバック** | 操作時に端末を微振動させるか。 | トグルスイッチ | ON / OFF | ON |

### ● 通知

*学習リマインダーやストリークに関する通知を設定する。*

| パラメータ | 概要 | UIコンポーネント | 選択肢 / 値 | デフォルト |
| --- | --- | --- | --- | --- |
| **学習リマインダー** | 毎日指定した時間に学習を促す通知を送るか。 | トグルスイッチ + 時刻設定 | ON / OFF | ON (20:00) |
| **ストリーク維持** | 学習ストリークが途切れそうな場合に通知を送るか。 | トグルスイッチ | ON / OFF | ON |
| **アプリアイコンバッジ** | アプリアイコンに表示する通知バッジの内容。 | ドロップダウン | 復習カード数, ストリーク日数, なし | 復習カード数 |
