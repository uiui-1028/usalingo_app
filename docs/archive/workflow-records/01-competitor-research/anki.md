# Anki 競合調査

> [!NOTE]
> **公式Web調査日: 2026-08-24 / 実機メモ統合日: 2026-08-27**

## 公式情報で確認できたこと

- デッキを選ぶと、新規・学習中・復習の件数を示す概要画面が出る。
- `Study Now` で、その日のカードがなくなるまで学習する。
- 問題だけを見て思い出し、答えを表示してから `Again / Hard / Good / Easy` で評価する。
- 評価ボタンには次回までの間隔が表示される。
- 4段階が難しい場合、公式マニュアルは `Again / Good` の2ボタン運用も案内している。

## 2026年の実機メモ

### 1問の流れ

```text
デッキ一覧
→ デッキを選ぶ

問題面
→ 自分で答えを思い出す
→ Show Answer

答え面
→ Again / Hard / Good / Easyで自己評価
→ スケジューラが次回間隔を計算
→ 次のカード

出題対象が0になる、または途中で離れる
→ 状態を保持して終了
```

- 実機では、デッキ選択後に学習がすぐ始まり、`New / Learning / Review` の概要や `Study Now` は確認できなかった。
- 学習中はいつでも離れられ、状態は保持される。固定枚数による明確な終了目安は見当たらなかった。

> [!CAUTION]
> 公式マニュアルの概要画面と今回の実機メモには差があります。Ankiの版、端末、設定、残カード状態による可能性があるため、「常に概要画面が出る」とは断定しません。

### 画面全体

- モバイル版はデッキ一覧を中心にした構成で、少ない操作で学習へ進める。
- 同期、デッキ追加・出力、設定、検索、アカウント、学習状況、Q&A等への補助導線がある。
- 学習方法と操作は細かく設定できる。
- スマホ上で新規カードを作成・設計する導線は習得負荷が高く、PC利用が一般的に見えた。
- 初期状態ではカードがないため、デッキ作成や共有デッキ導入を理解するまでの開始負荷が高い。

> [!IMPORTANT]
> **Usalingoへの仮説:** 復習計算と自動選択は採る。デッキ概要や件数確認は毎回見せず、「すぐ学ぶ」の後ろへ隠せる可能性がある。

> [!TIP]
> **追加の示唆:** デッキ一覧から学習へ進む短さを採る。一方、空の初期状態と複雑なカード作成は採らず、初回は標準デッキを自動設定する。
