# Usalingoの著作権・知的財産権について

状態: 公開前ドラフト

この文書は、Usalingoのコンテンツを安心して利用していただくための分かりやすい案内です。法的な利用条件は利用規約および個別に表示するライセンスが優先します。

## 1. Usalingoが提供するもの

アプリのソフトウェア、画面デザイン、ロゴ、独自の文章・例文、コンテンツの選択や構成、イラスト、音声等に関する権利は、法令上保護される範囲で、合同会社ImagiCraftまたは正当な権利者に帰属します。

個々の一般的な単語や事実など、著作権の対象とならないものまで当社が独占すると主張するものではありません。

## 2. 利用できる範囲

ユーザーは、Usalingo上で個人的な学習のためにコンテンツを利用できます。法令または個別ライセンスで認められる場合を除き、無断転載、再配布、販売、公開、改変しての商品化などはできません。

引用その他、著作権法で認められた利用を妨げるものではありません。

## 3. ユーザーが入力した内容

ニックネーム、タグ、単語の編集内容その他ユーザーが入力した内容の権利は、当社または第三者が従前から有する権利を除き、ユーザーに留保されます。当社は、サービスの保存、表示、バックアップ、不具合対応等に必要な範囲でのみ利用します。

現行アプリには、入力内容を他のユーザーへ一般公開する機能は確認されていません。将来共有機能を追加する場合は、公開範囲と利用許諾を事前に明示します。

## 4. 第三者の素材

オープンソースソフトウェア、フォント、音声、画像その他第三者が権利を有する素材には、それぞれのライセンスが適用されます。対象とライセンスは、公開前にアプリ内のクレジットまたはライセンス画面へ掲載します。

## 5. 権利侵害に関する連絡

Usalingo上のコンテンツがご自身の権利を侵害していると考える場合は、対象コンテンツ、権利の根拠、連絡先を添えて次の窓口へご連絡ください。内容を確認し、法令に従って対応します。
