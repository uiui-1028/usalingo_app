# Usalingo AI生成コンテンツガイドライン

状態: 機能導入前ドラフト・非公開  
適用開始日: 未定

## 適用前提

2026-08-16時点の現行iOSコードでは、ユーザーがAIでコンテンツを生成し、他のユーザーへ共有する機能は確認されていません。この文書は機能要件が確定するまで適用せず、公開もしません。

導入時には、利用するAI事業者、送信データ、学習利用の有無、生成物の保存・共有範囲、モデレーション、年齢制限、削除・異議申立て手順を確定したうえで全文を更新します。

## 1. 基本原則

1. 他者の権利、プライバシーおよび尊厳を尊重すること
2. 個人情報、秘密情報または入力権限のない資料をAIへ送信しないこと
3. 生成結果には誤りや偏りがあり得るため、利用・共有前にユーザー自身が確認すること
4. AI生成であることを、必要な場面で分かりやすく表示すること

## 2. 禁止する内容・利用

- 法令に違反し、犯罪を助長する内容
- 差別、脅迫、嫌がらせ、搾取、露骨な性的表現その他他者へ重大な害を与える内容
- 第三者の著作権、商標権、肖像、プライバシー、名誉その他の権利を侵害する内容
- 実在人物になりすます内容、または他人を欺く目的の内容
- 個人情報、認証情報、秘密情報を含む内容
- 教育用途を逸脱してサービスや安全対策を悪用する行為

## 3. 権利と利用許諾

生成物の権利は、適用法、入力素材の権利、利用するAI事業者の条件等によって異なります。当社は「すべての生成物の著作権が必ずユーザーに帰属する」とは保証しません。

サービス内で生成物を保存する場合、当社への利用許諾は、サービス提供、保存、表示、安全確認、不具合対応に必要な範囲へ限定します。一般公開、宣伝利用、AI学習への利用を行う場合は、目的と範囲を別途明示し、必要な同意を取得します。

## 4. 安全対策と措置

当社は、違反または重大な危険があると合理的に判断した場合、生成の拒否、非表示、削除、共有停止、機能制限、アカウント停止等の措置を講じることがあります。誤判定への問い合わせ・異議申立て手順は機能提供前に整備します。

## 5. 導入前に確定する事項

- AI事業者とモデル、各事業者の利用規約
- 入力・出力データの送信先、保存期間、学習利用の有無
- 生成・共有できるコンテンツ種別
- 自動検知と人による確認の範囲
- 通報、削除、異議申立て、権利侵害申告の手順と応答目標
- 未成年者に対する制限
- 商用利用の可否
- 利用規約・プライバシーポリシー・App Storeプライバシー回答との整合
