# 法務文書 公開前チェックリスト

更新日: 2026-08-16  
判定: 未完了。チェックがすべて埋まるまで公開しない。

## 1. 事業者情報

- [ ] 法人名を最新の登記簿と照合した
- [ ] 所在地を最新の登記簿および実際の活動場所と照合した
- [ ] 代表者・運営責任者・個人情報取扱責任者の氏名と役職を確定した
- [ ] 電話番号、受付時間、メールアドレスで実際に連絡を受けられる
- [ ] 裁判管轄を会社所在地、利用者保護、運用負担を踏まえて専門家と決定した

## 2. アプリとデータ

- [ ] リリース対象がiOSのみか、他のOSも含むか確定した
- [ ] 取得する全データをコード、Supabase、App Store Connectで照合した
- [ ] Supabaseプロジェクトの契約主体、リージョン、ログ項目、保存期間を確認した
- [ ] 委託先・SDKの一覧と各社の利用目的を確認した
- [ ] App StoreのPrivacy Nutrition Labelsと本ポリシーが一致している
- [ ] データ種別ごとの保存期間とバックアップ削除期間を決定した
- [ ] 開示・訂正・削除等の本人確認と受付手順を決定した
- [ ] 対象年齢、未成年者の同意方法、App Store年齢区分を決定した

## 3. アカウント削除

- [ ] アプリ内の見つけやすい場所からアカウント削除を開始できる
- [ ] Supabase Authと関連する個人データを削除するサーバー側手順を実装・検証した
- [ ] 削除対象、保持する例外、処理期間、復元不可を画面とポリシーに表示した
- [ ] 問い合わせによる削除受付と本人確認手順を用意した
- [ ] 有料購読導入時、アカウント削除と購読解約が別であることを案内した

## 4. 有料機能を導入する場合

- [ ] StoreKitと購入復元を実装・テストした
- [ ] App Store Connectのプラン名、期間、価格、地域を確定した
- [ ] 購入画面に総額、自動更新、解約、無料体験後の請求を明瞭に表示した
- [ ] 特定商取引法の表示事項を登記・販売条件と照合した
- [ ] App Storeの返金・購読管理への導線を確認した
- [ ] 利用規約とプライバシーポリシーへのリンクを購入画面とApp Storeメタデータに設置した

## 5. AI生成・共有機能を導入する場合

- [ ] AI事業者、モデル、送信データ、保存期間、学習利用の有無を確定した
- [ ] ユーザー入力と生成物の権利、利用許諾、公開範囲を確定した
- [ ] 禁止内容、モデレーション、通報、削除、異議申立てを実装した
- [ ] 未成年者、個人情報、権利侵害への対策を確認した
- [ ] AIガイドライン、利用規約、プライバシーポリシーを同時に更新した

## 6. 公開物

- [ ] 全文から `[要入力]`、`[要確認]`、`[要決定]`、`[公開前]` に相当する未確定表示を除いた
- [ ] 制定日、改定日、版番号を統一した
- [ ] アプリ内とApp Storeメタデータから利用規約・プライバシーポリシーへ容易に到達できる
- [ ] オープンソースおよび第三者素材のクレジット・ライセンス一覧を用意した
- [ ] 日本法に詳しい専門家による最終確認を受けた
- [ ] 公開URL、公開版のハッシュまたは版番号、公開日を記録した
