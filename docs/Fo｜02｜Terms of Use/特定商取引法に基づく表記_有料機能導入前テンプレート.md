# 特定商取引法に基づく表記

状態: 有料機能導入前テンプレート・非公開  
最終確認日: 未定

現行iOSコードではStoreKitによる販売機能を確認できないため、この文書を販売表示として公開しません。有料機能の実装、App Store Connectの設定、価格および提供条件が確定した時点で、登記・受付体制と照合して完成させます。

| 項目 | 公開前に確定する内容 |
| --- | --- |
| 販売事業者 | 合同会社ImagiCraft [登記簿の表記と照合] |
| 代表者または通信販売業務の責任者 | [氏名・役職を確定] |
| 所在地 | [現に活動している所在地を登記簿と照合して記載] |
| 電話番号 | [確実に連絡できる番号、受付時間を実際の体制と照合] |
| メールアドレス | taiga@usalingo.jp [受信・返信可能か確認] |
| 販売価格 | App Storeの購入画面に税込総額を表示。プラン名、期間、更新時の総額を一致させる |
| 商品代金以外の必要料金 | インターネット接続・通信料金はユーザー負担 |
| 支払方法 | Apple App Storeのアプリ内課金 [StoreKit実装後に確定] |
| 支払時期 | 購入時および自動更新時 [App Store Connect設定と照合] |
| 提供時期 | 購入処理完了後、直ちに利用可能 [実装で確認] |
| 自動更新 | 更新期間、更新価格、更新停止期限、管理画面への導線を記載 |
| 解約方法 | App Storeのサブスクリプション管理手順とアプリ内導線を記載。アプリ削除・アカウント削除との違いを明示 |
| 返品・キャンセル・返金 | デジタルサービスの性質、Appleの返金手続、法令上認められる権利を踏まえて確定 |
| 動作環境 | 現行コードはiOS 17.0以降。公開時のApp Store要件と実機確認結果に更新 |
| 申込期間 | 期間限定の申込みがある場合のみ、その期間を表示 |

## 購入画面でも表示する事項

- プラン名と提供内容
- 購読期間
- 実際に請求される税込総額
- 自動更新されることと更新価格
- 無料体験がある場合、その期間と終了後の請求額
- 購入の復元方法
- 解約・購読管理への導線
- 利用規約とプライバシーポリシーへのリンク

価格をこのファイルへ固定記載する場合は、App Store Connectの全地域・全プランと不一致がないことを公開直前に再確認します。
