合同会社ImagiCraft（以下「当社」）は、学習アプリケーション「Usalingo」およびこれに付随するサービス（以下「本サービス」）における利用者情報を、次のとおり取り扱います。

## 1. 取得する情報

### ユーザーが入力する情報

- メールアドレス
- 認証に必要な情報。パスワード認証はSupabase Authを通じて処理されます
- ニックネーム
- 問い合わせ時に送信する連絡先、本文その他の情報

### 本サービスの利用に伴う情報

- 利用者ID
- 学習したカード、正誤、反復回数、苦手情報、復習予定、学習日時等の学習履歴
- ユーザーが設定した単語の編集内容およびタグ
- 認証セッション情報。端末のKeychainに保存します
- アクセント色、カード表示等の端末内設定。UserDefaultsに保存します
- 通信時に通常付随するIPアドレス、リクエスト日時、エラー情報等。[Supabase側の実際のログ項目と保存期間を要確認]

現行iOSコードでは、広告SDK、専用のアクセス解析SDK、位置情報、連絡先、写真、マイク、カメラを利用する実装は確認されていません。公開前およびSDK追加時に再監査します。

## 2. 利用目的

当社は、取得した情報を次の目的で利用します。

1. アカウントの作成、認証および維持
2. 学習コンテンツ、復習予定、学習履歴、ユーザー設定等の提供
3. 問い合わせ対応および重要な連絡
4. 障害の調査、セキュリティ確保、不正利用の防止
5. 本サービスの品質改善。ただし、新たな分析用途に利用する場合は必要な表示・同意を整備します
6. 法令上の義務への対応

利用目的を、本人が通常予測できない範囲へ変更する場合は、法令に従って通知または同意取得を行います。

## 4. 第三者提供

当社は、次の場合を除き、本人の同意なく個人データを第三者へ提供しません。

1. 法令に基づく場合
2. 人の生命、身体または財産の保護のために必要で、本人の同意を得ることが困難な場合
3. 公衆衛生の向上または児童の健全な育成のために特に必要で、本人の同意を得ることが困難な場合
4. 国または地方公共団体等の法定事務への協力が必要で、本人の同意によりその遂行に支障が生じるおそれがある場合
5. 合併、事業譲渡その他の事業承継に伴う場合
6. その他、個人情報保護法で認められる場合

2. アカウント削除の申込み後、法令上の保存義務、紛争対応、セキュリティ確保その他正当な必要がある情報を除き、[削除完了までの期間を要決定]以内に削除または個人との対応関係を除去します。
