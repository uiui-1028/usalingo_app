# 依存関係クリーンアップスクリプト

## 完了日: 2025年1月27日

## 概要
`audio_asset_path`カラムの削除時に発生する依存関係エラーを解決するための段階的クリーンアップスクリプト。

## 実行順序

### ステップ1: ビューの削除
```sql
-- 依存するビューを削除
DROP VIEW IF EXISTS v_word_meanings_with_paths;
DROP VIEW IF EXISTS v_example_contents_with_paths;
```

### ステップ2: トリガーの削除
```sql
-- 依存するトリガーを削除
DROP TRIGGER IF EXISTS trigger_word_meanings_asset_linking ON word_meanings;
DROP TRIGGER IF EXISTS trigger_example_contents_asset_linking ON example_contents;

-- トリガー関数も削除（必要に応じて）
DROP FUNCTION IF EXISTS trigger_asset_linking();
```

### ステップ3: asset_pathカラムの削除
```sql
-- word_meaningsテーブルからaudio_asset_pathカラムを削除
ALTER TABLE word_meanings DROP COLUMN IF EXISTS audio_asset_path;

-- example_contentsテーブルからasset_pathカラムを削除
ALTER TABLE example_contents DROP COLUMN IF EXISTS illustration_asset_path;
ALTER TABLE example_contents DROP COLUMN IF EXISTS audio_asset_path;
```

### ステップ4: 不要な拡張子カラムの削除
```sql
-- 固定形式のため不要な拡張子カラムを削除
ALTER TABLE word_meanings DROP COLUMN IF EXISTS audio_ext;
ALTER TABLE example_contents DROP COLUMN IF EXISTS illustration_ext;
ALTER TABLE example_contents DROP COLUMN IF EXISTS audio_ext;
```

### ステップ5: 新しいビューの再作成（オプション）
```sql
-- 関数ベースでのパス生成に対応した新しいビュー
CREATE OR REPLACE VIEW v_word_meanings_with_paths AS
SELECT 
    id,
    word_id,
    priority,
    part_of_speech_en,
    part_of_speech_jp,
    definition_jp,
    cefr_level,
    etymology,
    synonyms,
    antonyms,
    pronunciation_ipa,
    pronunciation_kana,
    pronunciation_cmu,
    audio_filename,
    inflections,
    derivatives,
    collocations,
    related_phrases,
    created_at,
    updated_at,
    -- 新命名規則でのパス生成
    get_audio_meaning_path(id) AS audio_path
FROM word_meanings wm;

CREATE OR REPLACE VIEW v_example_contents_with_paths AS
SELECT 
    id,
    meaning_id,
    theme,
    sentence_en,
    sentence_jp,
    illustration_filename,
    audio_filename,
    created_at,
    updated_at,
    -- 新命名規則でのパス生成
    get_image_example_path(id) AS illustration_path,
    get_audio_example_path(id) AS audio_path
FROM example_contents ec;
```

## 実行結果
✅ **成功** - 全てのステップが正常に完了

## 注意事項

1. **バックアップ**: 実行前にデータベースのバックアップを取ることを推奨
2. **段階的実行**: 各ステップを個別に実行し、エラーがないか確認
3. **依存関係の確認**: 他のオブジェクトが削除されたビューやトリガーに依存していないか確認
4. **アプリケーションの対応**: クライアントアプリケーションが新しいビュー構造に対応していることを確認
