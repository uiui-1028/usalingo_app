# タスク02: タイムスタンプカラムの追加

## 📋 概要
**優先度:** 🔴 高優先度（すぐに対応すべき）

主要テーブルに`created_at`と`updated_at`カラムを追加し、更新時の自動更新トリガーを実装する。

## 🎯 目的
- データの作成・更新履歴を追跡可能にする
- デバッグやデータ分析を容易にする
- 監査証跡を確保する

## ❌ 現在の問題

```sql
-- 現在の設計（タイムスタンプなし）
CREATE TABLE public.words (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    word_text TEXT NOT NULL UNIQUE
);
```

**影響:**
- データの作成・更新履歴が追跡できない
- デバッグやデータ分析が困難
- 監査証跡が不足

## ✅ 改善案

```sql
-- タイムスタンプカラムを追加
ALTER TABLE public.words 
ADD COLUMN created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
ADD COLUMN updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW();

ALTER TABLE public.word_meanings 
ADD COLUMN created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
ADD COLUMN updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW();

ALTER TABLE public.example_contents 
ADD COLUMN created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
ADD COLUMN updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW();

ALTER TABLE public.decks 
ADD COLUMN created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
ADD COLUMN updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW();

ALTER TABLE public.card_templates 
ADD COLUMN created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
ADD COLUMN updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW();
```

### 自動更新トリガーの実装

```sql
-- updated_atを自動更新する汎用トリガー関数
CREATE OR REPLACE FUNCTION public.update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- 各テーブルにトリガーを設定
CREATE TRIGGER update_words_updated_at
    BEFORE UPDATE ON public.words
    FOR EACH ROW
    EXECUTE FUNCTION public.update_updated_at_column();

CREATE TRIGGER update_word_meanings_updated_at
    BEFORE UPDATE ON public.word_meanings
    FOR EACH ROW
    EXECUTE FUNCTION public.update_updated_at_column();

CREATE TRIGGER update_example_contents_updated_at
    BEFORE UPDATE ON public.example_contents
    FOR EACH ROW
    EXECUTE FUNCTION public.update_updated_at_column();

CREATE TRIGGER update_decks_updated_at
    BEFORE UPDATE ON public.decks
    FOR EACH ROW
    EXECUTE FUNCTION public.update_updated_at_column();

CREATE TRIGGER update_card_templates_updated_at
    BEFORE UPDATE ON public.card_templates
    FOR EACH ROW
    EXECUTE FUNCTION public.update_updated_at_column();
```
