# 🚀 ストレージファイル移行 実行ガイド

## 📋 概要

このディレクトリには、Supabase Storageのファイルを階層構造に移行するためのスクリプトが含まれています。

---

## ⚠️ 実行前の重要確認事項

### 必須条件
- ✅ データベースのバックアップを取得済み
- ✅ Supabase管理画面でのバックアップ作成済み
- ✅ Service Role Keyを取得済み
- ✅ リスクを理解している

### リスク理解
- ❌ **この操作は元に戻せません**
- ❌ **約3,000ファイルが対象**
- ❌ **アプリがダウンタイムする可能性**
- ❌ **失敗するとファイルにアクセスできなくなる**

---

## 🛠️ 準備

### 1. 環境変数の設定

```bash
# Supabase URLとService Role Keyを設定
export SUPABASE_URL="https://your-project.supabase.co"
export SUPABASE_SERVICE_ROLE_KEY="your-service-role-key"
```

**Service Role Keyの取得方法:**
1. Supabaseダッシュボード → Settings → API
2. "service_role" の "secret" をコピー

### 2. Denoのインストール（推奨）

```bash
# macOS/Linux
curl -fsSL https://deno.land/install.sh | sh

# または Homebrew
brew install deno
```

---

## 📦 実行手順

### ステップ1: バックアップの取得

```bash
cd docs/supabase/storage-migration

# バックアップスクリプトを実行
deno run --allow-net --allow-env --allow-write 01_backup_script.ts
```

**確認事項:**
- `./backup/content-images/` にファイルがダウンロードされる
- `./backup/content-audio/` にファイルがダウンロードされる
- 合計約3,000ファイルが保存される

**重要**: バックアップが完全に完了するまで次に進まないでください！

---

### ステップ2: テスト移行（ID 1-5のみ）

```bash
# テスト移行を実行
deno run --allow-net --allow-env 02_migration_script.ts --test
```

**確認事項:**
- 5件のファイルが正常に移行される
- エラーが発生しないか確認
- Supabase管理画面で新しいフォルダ構造を確認

**新しいフォルダ:**
- `content-images/シンプル/0000-0199/` にファイルが存在するか
- `content-audio/example/シンプル/0000-0199/` にファイルが存在するか

---

## 🐛 トラブルシューティング

### エラー: "Rate limit exceeded"

**原因**: Supabaseのレート制限に達した

**対策**:
```typescript
// 02_migration_script.ts の待機時間を増やす
await new Promise(resolve => setTimeout(resolve, 200)) // 100 → 200に変更
```

### エラー: "File not found"

**原因**: 旧パスのファイルが存在しない

**対策**:
1. データベースの`*_asset_path`を確認
2. 実際にファイルが存在するか管理画面で確認
3. 欠損ファイルをスキップして続行

### 移行が途中で止まった

**対策**:
1. エラーログを確認
2. 失敗したIDを特定
3. そのバッチのみ再実行
