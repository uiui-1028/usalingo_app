# フォルダ分割数移行手順書（200→500ファイル/フォルダ）

## 📋 概要

この手順書は、Supabase Storageのフォルダ分割数を200ファイル/フォルダから500ファイル/フォルダに移行するための詳細な手順を説明します。

## 🎯 移行の目的

- **管理性の向上**: フォルダ数を削減し、管理しやすくする
- **将来対応**: データ増加に対応できる構造に変更
- **パフォーマンス維持**: Supabase制限（200ファイル）を大幅に下回る
- **運用効率**: フォルダ数が適度で、ナビゲーションが容易

## 📊 移行前後の比較

| 項目 | 移行前（200ファイル/フォルダ） | 移行後（500ファイル/フォルダ） |
|------|------------------------------|------------------------------|
| **現在のフォルダ数** | 5フォルダ | 2フォルダ |
| **2年後のフォルダ数** | 10フォルダ | 4フォルダ |
| **管理性** | やや多い | 最適 |
| **パフォーマンス** | 高速 | 高速 |
| **将来対応** | 良い | 最適 |

## ⚠️ 注意事項

### 移行中の制限事項
- **移行中はアプリケーションを停止**: ファイル移動中はアクセスエラーが発生する可能性
- **ネットワーク接続の安定性**: 大量のファイル移動のため、安定した接続が必要
- **API制限**: SupabaseのAPI制限により、移行に時間がかかる場合がある

### ロールバック手順
```bash
# バックアップから復元
supabase db reset --file backup_before_migration.sql

# Storageの手動復元
# バックアップしたファイルをアップロード
```
