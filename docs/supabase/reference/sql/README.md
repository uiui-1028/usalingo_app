# 🗄️ SQL リファレンス

データベース関連のSQLファイルが統合されて整理されています。

## 📂 ファイル構成

### `consolidated/` - 統合SQLファイル
実行順序に従って統合されたSQLファイル

1. **`00_setup.sql`** - データベース初期化
   - 既存テーブルのクリーンアップ
   - データベース初期設定

2. **`01_core_schema.sql`** - コアスキーマ
   - テーブル定義
   - 基本インデックス
   - Row Level Security

3. **`02_features.sql`** - 基本機能
   - トリガー関数
   - タイムスタンプ機能

4. **`03_performance.sql`** - パフォーマンス最適化
   - 全文検索インデックス
   - 複合インデックス

5. **`04_storage.sql`** - ストレージ機能
   - ストレージ設定
   - 階層化構造

6. **`05_documentation.sql`** - ドキュメント
   - JSONB構造定義
   - コメント追加

## 🚀 使用方法

### 新規環境でのセットアップ
```bash
# 順番に実行
00_setup.sql
01_core_schema.sql
02_features.sql
03_performance.sql
04_storage.sql
05_documentation.sql
```

### 既存環境での機能追加
- 必要な機能のSQLファイルのみを実行
- 実行前に必ずバックアップを取得

## ⚠️ 注意事項

- **バックアップ**: 実行前に必ずデータベースのバックアップを取得
- **テスト環境**: 可能な限り開発環境で先にテスト
- **段階的実行**: 一度に全てを実行せず、段階的に確認
