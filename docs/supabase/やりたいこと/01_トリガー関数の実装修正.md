# タスク01: トリガー関数の実装修正

## 📋 概要
**優先度:** 🔴 高優先度（すぐに対応すべき）

現在の`04_media_trigger.sql`のトリガー関数が実際のパス設定を行っていない問題を修正する。

## 🎯 目的
- トリガー関数を実際にアセットパスを設定する実装に更新
- Supabaseにデプロイ済みの正しい実装とSQLファイルを同期
- 自動紐付け処理の完全な動作を保証

## ❌ 現在の問題

```sql
-- 現在の04_media_trigger.sql
CREATE OR REPLACE FUNCTION public.trigger_asset_linking()
RETURNS TRIGGER AS $$
BEGIN
    -- ログ出力のみで実際の処理がない
    RAISE LOG 'アセット紐付け処理がトリガーされました...';
    RETURN COALESCE(NEW, OLD);
END;
$$ LANGUAGE plpgsql;
```

**影響:**
- トリガーが実際にアセットパスを設定していない
- 手動でのパス設定が必要
- 自動化の利点が活かせていない

## ✅ 改善案

```sql
-- Supabaseに既にデプロイ済みの実装（修正版）
CREATE OR REPLACE FUNCTION public.trigger_asset_linking()
RETURNS TRIGGER AS $$
BEGIN
    -- word_meaningsテーブルの場合
    IF TG_TABLE_NAME = 'word_meanings' THEN
        IF NEW.audio_url IS NOT NULL AND NEW.audio_asset_path IS NULL THEN
            NEW.audio_asset_path := 'content-audio/' || NEW.audio_url;
        END IF;
    END IF;
    
    -- example_contentsテーブルの場合
    IF TG_TABLE_NAME = 'example_contents' THEN
        IF NEW.illustration_url IS NOT NULL AND NEW.illustration_asset_path IS NULL THEN
            NEW.illustration_asset_path := 'content-images/' || NEW.illustration_url;
        END IF;
        
        IF NEW.audio_url IS NOT NULL AND NEW.audio_asset_path IS NULL THEN
            NEW.audio_asset_path := 'content-audio/' || NEW.audio_url;
        END IF;
    END IF;
    
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```
