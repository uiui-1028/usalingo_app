# Usalingo 学習ワークフローと初期機能要件

状態: **決定済み**

決定日: 2026-08-27

> [!IMPORTANT]
> 初回はアンケートなしで標準デッキを自動設定し、2回目以降はデッキ一覧から始めます。学習は、実装済みの正解／不正解による2段階SM-2ハイブリッドへ一本化します。

## 決めたこと

### 初回体験

```text
初回起動
→ ゲストとして開始
→ アンケートなし
→ 初回だけ操作ヒント
→ 管理側の標準デッキを自動設定
→ 学習開始
```

強制アカウント登録と強制設定は行いません。ゲストの学習記録は、アカウント作成後も失わず引き継ぐことを製品要件とします。具体的な保存・移行方法は別途設計します。

### 2回目以降

```text
学習タブのデッキ一覧
→ デッキをタップ
→ 設定画面なしで学習開始
```

デッキ編集は通常タップと分け、長押し、スワイプ、iOS標準に近いコンテキスト操作で行います。

### 学習中

- 復習カードか新しいカードかを利用者に選ばせない。
- SRSが次のカードを自動決定する。
- タップで答えを表示する。
- 答えを表示しただけでは次へ進まない。
- 右スワイプを正解、左スワイプを不正解とする。
- 直前の誤評価をUndoできる。
- 途中で離れた状態を保存する。

### Complete

- 固定の1セッション枚数や「今日のノルマ」は設けない。
- 初回は、標準デッキの初回対象カードをすべて処理した状態をCompleteとする。
- その後は、現在出題可能なカードが0枚になった状態をCompleteとする。
- 初期表示は簡潔な `Complete` のみでよい。
- 途中終了はCompleteではなく中断とする。

## 復習アルゴリズム

現在実装済みの**2段階SM-2ハイブリッド**を採用します。

| 回答 | 現在の処理 |
|---|---|
| 1回目の正解 | 1日後 |
| 2回目の正解 | 6日後 |
| 3回目以降の正解 | 前回間隔 × 易しさ係数 |
| 不正解 | 連続正解を0、間隔を1日、学習レベルを1へ戻す |

これはAnki型の自動復習を初心者向けに2段階へ簡略化したもので、Ankiの `Again / Hard / Good / Easy` を完全に複製するものではありません。

## 採用する初期機能

| 領域 | 採用するもの |
|---|---|
| 学習タブ | デッキ一覧、名前、総数、学習可能数、表紙、追加・削除・名前変更・並び替え、長押し、Empty State |
| 公式デッキ追加 | 一覧、詳細、ダウンロード、単語数、レベル、CEFR等、目的、表紙、取得済み表示、容量 |
| 回答操作 | 左右スワイプ、ドラッグ追従、傾き、Haptics、Undo |
| 学習補助 | 単語音声、例文音声、お気に入り、統合したコンテンツ誤り報告、単語詳細、タグ |
| Complete | 簡潔なComplete表示 |
| 学習記録 | 学習済み単語数、学習日数、ストリーク、学習ヒートマップ |
| 単語一覧 | デッキ内一覧、検索、英単語、日本語訳 |
| Account | ゲスト表示、作成、ログイン、履歴引き継ぎ、メール・パスワード変更、ログアウト、規約、プライバシー、ライセンス、問い合わせ、バージョン |

「デッキ追加」は、運営が用意した公式デッキを端末へ追加する意味です。利用者が自作デッキを作る機能は含みません。

## 今回は含めないこと

- 学習開始前の設定画面。
- 固定のセッション枚数、新規／復習の日次上限。
- 新規のみ、復習のみ、通常学習、フリー学習などのモード選択。
- Ankiの4段階評価、回答ボタン、キーボード回答。
- Completeの正解率、枚数、時間、次回日、ストリーク、共有、再学習CTA。
- 自作デッキ、デッキ共有、デッキ検索、人気順、新着順、おすすめ。
- 詳細統計、詳細学習履歴、月次／年次レポート。
- 課金、プラン管理、通知、同期状態の常時表示。
- Design / Adaptive Space、学習画面の具体的な配置、SRS詳細設定、Offline / Syncの詳細設計。

アカウント削除はこのワークフロー整理の対象外ですが、既存の[`account-deletion-contract.md`](../architecture/account-deletion-contract.md)を削除または無効化する決定ではありません。

## 既存実装との関係

### コードで確認できたもの

- `LearningProgress.marking` に2段階SM-2ハイブリッドがある。
- `StudySessionView` に右／左スワイプ、ドラッグ追従、傾き、タップで答え表示、Undoがある。
- `LearningProgressTests` に正解時の1日・6日・係数間隔、不正解時のリセット、Undoのテストがある。

### まだ決定と一致していないもの

- アンケート画面と関連テストが残っている。
- 学習画面に正解／不正解の回答ボタンが残っている。
- 新規のみ／復習のみ等の学習モードが残っている。
- Complete画面に正解数などの詳細情報が残っている。
- 初回自動開始から2回目以降のデッキ一覧までの通し動作は、この決定時点では確認していない。

## 理由

- 初回の選択をなくし、イラスト付き英単語の体験へ早く届けるため。
- 2回目以降は、利用者が学びたい公式デッキを選べるようにするため。
- 既存の2段階アルゴリズムと操作を再利用し、作り直しを避けるため。
- 「現在やるべきカードがない」というSRSの状態を、固定ノルマより優先するため。

## 見直す条件

- 2段階評価では学習精度を保てない根拠が得られたとき。
- 固定上限なしでは初回学習が長すぎると確認されたとき。
- ゲスト履歴の安全な移行方法が成立しないとき。
- App Store、法務、アクセシビリティの要件と衝突するとき。
